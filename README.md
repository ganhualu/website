## README

This repository hosts Ganhua Lu's personal website built with [Quarto](https://quarto.org/) and rendered with Github Pages.

Reference: https://github.com/elizabethmcd/elizabethmcd.github.io/tree/main

The site was built using option 1 of the instructions for rendering with Github pages [described here](https://quarto.org/docs/publishing/github-pages.html). The website is rendered to the docs directory by modifying the _quarto.yml file

Render your site and push it to GitHub:

```{Terminal}
quarto render
git add docs
git commit -m "Publish site to docs/"
git push
```
